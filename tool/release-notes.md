BookShelf for the PRM393 practical exam by Phạm Huỳnh Sum (QE190117).

Includes Firebase Email/Password authentication, a private book collection, validated add/edit/delete forms, persistent favorites, realtime updates, combined filters/search and visible-result statistics.

Download app-release.apk and install it on Android. The app connects to the configured Firebase project. The grader account credentials are supplied privately with the handover/report.

Version 1.0.1 fixes duplicate-book error messages on Web and scrolls the List back to the confirmation after adding a book. Validated with 14 Flutter tests and a manual Web session covering authentication, CRUD, favorites, combined filtering, summaries and persistence.
